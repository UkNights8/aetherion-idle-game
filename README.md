# Aetherion: Cosmic Singularity | Idle Progression Game

> Премиальная инкрементальная Idle-игра с продвинутым математическим ядром, ступенчатыми множителями (Milestone Multipliers), механикой престижа (Soft Reset), оффлайн-прогрессом и звуковым синтезатором Web Audio API.

Разработано в строгом соответствии с технической спецификацией (`technical_specification_idle_progression.md`).

---

## 🌌 Основные механики

1. **Математическая модель больших чисел (`BigNum`)**:
   - Поддержка экспоненциальных чисел до $10^{1\,000\,000+}$ (выход за пределы лимита IEEE 754 $1.79 \times 10^{308}$).
   - 3 переключаемых формата: **Standard** (M, B, T, Qa, Qi...), **Scientific** (`1.54e15`) и **Engineering** (`154.20e12`).
2. **Аналитические формулы Bulk Buy (x1, x10, x100, MAX)**:
   - Аналитический расчет стоимости за $O(1)$ без циклических итераций:
     $$Cost(n, k) = BaseCost \times \frac{Multiplier^n \times (Multiplier^k - 1)}{Multiplier - 1}$$
     $$k_{max} = \left\lfloor \log_{Multiplier} \left( \frac{c \times (Multiplier - 1)}{BaseCost \times Multiplier^n} + 1 \right) \right\rfloor$$
3. **Ступенчатые вехи (Milestones)**:
   - x2 (ур. 25), x4 (ур. 50), x8 (ур. 100), x4 за каждые следующие 100 уровней, x10 (ур. 1000).
4. **Система Престижа (Soft Reset)**:
   - Формула начисления Осколков Сингулярности (порог 1 млрд монет):
     $$P_{earned} = \max\left(0, \left\lfloor 150 \times \sqrt{\frac{E_{total}}{10^{9}}} \right\rfloor - P_{current\_spent\_and\_held}\right)$$
   - Глобальный множитель: $Mult_{global} = 1 + (P_{held} \times 0.02)$.
   - Древо перманентных мета-улучшений (резонанс осколков, расширение оффлайна, демпинг цен, импульс клика).
5. **Оффлайн-прогресс**:
   - $OfflineEarnings = \min(\Delta t, TimeLimit) \times Production_{total} \times Efficiency$.
   - Защита от перевода системных часов и диалог возвращения с оверчарджем x2.
6. **Аудио и Визуальные эффекты**:
   - Синтезатор Web Audio API (звуки лазерных кликов, покупок, майлстоунов, престижа).
   - Анимированный Квантовый Реактор с частицами на Canvas.

## 🎮 Запуск

Игра не требует сборки, сторонних зависимостей или компиляторов:
1. Склонируйте репозиторий или скачайте архив.
2. Откройте `index.html` в любом современном браузере.

## 🧪 Тестирование и QA

В игру встроен автоматизированный тест-кит (вкладка **Настройки** -> **QA Диагностика**), проверяющий:
- Точность Bulk Buy (погрешность $< 0.0001\%$).
- Формулы престижа и матрицу сброса.
- Оффлайн-расчеты и ограничение 2 часов.
- Числа $> 10^{308}$ и стабильность UI.
